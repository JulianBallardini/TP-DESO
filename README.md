# TP-DESO - Sistema de Evaluación de Candidatos

Aplicación full-stack para la gestión y evaluación de candidatos en procesos de selección,
desarrollada como trabajo práctico para las materias "Diseño de Sistemas de Información" (DDS)
y "Desarrollo de Software" (DESO) de la UTN.

## Funcionalidades planificadas

El sistema implementará los casos de uso definidos en el enunciado del TP:

- CU 01: Autenticar usuario
- CU 06: Importar candidatos
- CU 09: Dar de alta puesto
- CU 13: Dar de alta competencia
- CU 17: Dar de alta factor
- CU 20-23: Gestión de preguntas (alta, modificación, baja)
- CU 24-29: Gestión de opciones de respuesta (alta)
- CU 25: Evaluar candidatos
- CU 26: Completar cuestionario
- CU 28: Emitir orden de mérito
- CU 33: Generar pregunta con IA (opcional)

## Stack tecnológico

- Backend: Java 17+ con Spring Boot (API REST, patrón DAO)
- Frontend: Next.js (React)
- Base de datos: relacional (PostgreSQL/MySQL/SQLite)
- Testing: JUnit 5 + Mockito

## Estructura del repositorio

- `Backend/`: API REST en Spring Boot
- `Frontend/`: aplicación web en Next.js
- `Enunciado/`: enunciado del trabajo práctico (PDF)
